    # Crown Wedding Films Website
   Overview
Crown Wedding Films is a modern, elegant website for a wedding photography and cinematography business based in Addis Ababa, Ethiopia. The website showcases wedding galleries, featured videos, and provides information about the company’s services.  
The design focuses on a clean, responsive layout with:  
 Hero section with background image and styled text, Photo gallery with neatly arranged images, Featured wedding films displayed horizontally, Fixed logo and navigation bar for easy access, Responsive and visually appealing design  

     ## Features
-Responsive Layout: Works on desktop and mobile screens  
-Hero Section: Background image with overlay and highlighted text  
 -Gallery Section: Grid layout with neatly cropped images  
 -Video Section: Horizontal layout featuring two wedding films  
 -Navigation: Fixed logo and smooth hover effects on links  
 -Footer: Simple and clean footer with company info  
 
     ## Technologies Used
 HTML5: Page structure and content
- CSS3: Styling, layout, transparency, and responsiveness
- JavaScript: Interactivity and animation
- Git & GitHub: Version control and progress tracking
- VS Code: Code editor
- Live Server: Local testing environment
